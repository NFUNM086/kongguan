一、引言

1.1 项目背景

空间数据管理中心负责三维空间数据的统一接入、管理、处理、服务发布与统计分析，为上层数字孪生可视化平台提供数据支撑。

1.2 适用用户

角色 核心场景
信息化与技术支持人员 模型上传、格式转换、服务发布、系统管理
生产调度与工艺人员 模型预览查看、场景服务浏览
管理决策层 空间数据统计图表查看

核心业务路径：

1. 模型上传与检测：登录 → 源模型管理 → 模型上传（7 类入口）→ 模型检测（自动触发）→ 检测通过回到源模型管理列表

2. 格式转换与轻量化：源模型管理或我的模型库 → 提交任务 → 任务管理监控进度 → 处理完成可添加至我的模型库

3. 服务发布：我的模型库 → 发布模型服务 → 模型服务管理 → 多个模型服务组合为场景服务

4. 预览：源模型管理需先"添加至模型库"后预览，或先执行格式转换生成任务后预览

交互流程：

1. 模型上传完成后出现在列表中，状态为"检测中"时等待系统自动检测，无操作按钮，状态列展示橙色圆点

2. 检测通过 → 状态变为"上传成功"，状态列展示绿色圆点，可执行格式转换、轻量化或添加至模型库

3. 源模型管理页面不能直接预览——需先执行格式转换生成任务后预览，或"添加至模型库"后通过我的模型库预览

4. 点击"添加至模型库"→ 按钮先进入 loading 加载状态（显示加载动画，按钮暂时不可点击），待后端返回成功后，按钮变为"查看"（点击可跳转预览查看），同时弹出成功提示弹窗

5. 【添加至模型库】与【格式转换】的任务区别：
• 点击【添加至模型库】：由后台被动将模型转换为可预览格式，转换过程在不可见的后台文件夹中进行，不在【任务管理】中生成可见任务；
• 点击【格式转换】：为用户主动发起的任务，需在【任务管理】中生成一条可见任务，供跟踪进度与结果

6. 检测不通过 → 状态列展示红色圆点，hover"可能原因"图标查看提示，点击"重新上传"重新选择文件

7. 格式转换限制：GLB 和 DXF 不支持格式转换；已转换过的模型不能再次转换

8. 轻量化限制：仅 GLB 可轻量化（手工模型和 BIM 数据后台自动转 GLB 后也支持），已轻量化的可再次轻量化但不保证成功

9. 表格列表支持多选勾选，配合"批量下载"、"批量删除"按钮使用；勾选后按钮从禁用态变为可用态

3.3 模型上传

对应原型文件： 模型上传.html

功能描述： 三维模型上传入口，按数据类型分为 7 个入口，各有不同的格式支持和大小限制。上传完成后自动触发模型检测流程，模型同时出现在源模型管理列表中。

页面结构：

  • 7 类上传入口（初始无数据标签下）：
数据分类 上传按钮 格式说明 大小限制
BIM数据 上传BIM数据 RVT、PLN 单文件（不支持压缩包），RVT 仅限 Revit2021 及更早版本 ≤500M
手工模型 上传手工模型 OBJ、FBX、STL、3DS 单文件（不支持压缩包） ≤500M
倾斜摄影 上传倾斜摄影 OSGB，需打包为 ZIP/RAR 压缩包上传（唯一支持压缩包的格式） ≤10G
地形数据 上传地形数据 TIFF、DEM 单文件（不支持压缩包） ≤500M
影像数据 上传影像数据 TIFF 单文件（不支持压缩包） ≤500M
点云数据 上传点云数据 PCD、PLY、TXT、LAS 单文件（不支持压缩包） ≤500M
CAD数据 上传CAD数据 DXF、DWG、DWF、DGN 单文件（不支持压缩包） ≤500M

默认状态：选中 BIM数据 分类，右侧面板展示对应格式说明和大小限制。

  • 上传流程：

1. 用户在初始无数据标签下，左侧点击分类标签，右侧面板切换展示对应分类的格式说明和大小限制

2. 点击"上传[分类名]"按钮 → 系统弹出系统文件选择窗口（由浏览器/操作系统原生提供），文件选择过滤器仅展示该分类支持的格式；仅倾斜摄影分类接受 ZIP/RAR 压缩包（内含 OSGB），其余分类只接受各自格式的单文件

3. 用户选择文件并确认后，上传开始——此时：

  • 文件开始上传至后端，上传进度可展示在按钮区域（如按钮文案变为"上传中…"并置灰禁用，避免重复点击）
  • 上传完成后自动触发模型检测流程（详见 3.4）
  • 模型同时出现在"已有数据"标签页的表格和源模型管理列表中

4. 上传前的客户端校验：

  • 文件大小：若超过该分类的大小限制，前端拦截并提示"文件大小超过限制（≤XXX），请重新选择文件"
  • 文件格式：若文件扩展名不在该分类支持的格式列表中，前端拦截并提示"文件格式不支持，请选择 XXX 格式文件"

3.4 模型检测

对应原型文件： 模型检测.html

功能描述： 上传完成后自动触发的检测流程，验证文件大小合规性、可读性。RVT 额外判断 Revit 版本是否超过 2021；OSGB 压缩包额外校验包内文件格式是否正确。

页面结构：

  • 进度阶段标题： 上传模型 / 检测中 / 检测通过
  • 表格： 与源模型管理同结构
  • 操作按钮： 重置、批量下载、批量删除；行内 重新上传、格式转换、添加至模型库、删除、取消上传、后台上传

检测结果弹窗（3 种状态）：

状态1 — 检测进行中：

  • 模型上传完成后自动触发检测流程，此时弹出检测进度弹窗：
  • 弹窗顶部展示 loading 动效，下方显示文案"正在检测中，请稍候……"
  • 弹窗底部提供两个操作按钮：后台上传、取消上传
  • 后台上传： 用户点击"后台上传"后，弹窗关闭，检测任务转为异步执行，不阻塞用户继续操作，用户可继续上传其他模型或浏览其他页面。检测完成后，模型状态自动更新为"上传成功"或"检测不通过"，无需用户手动刷新。
  • 取消上传： 用户点击"取消上传"后，弹窗关闭，同时中断当前上传和检测流程，该条上传记录从列表中移除，不保留在源模型管理中。
  • 等待期间： loading 动效持续播放，弹窗不自动关闭，用户必须选择"后台上传"或"取消上传"其中之一才能关闭弹窗继续操作。

状态2 — 检测通过：

  • 绿色确认图标
  • 文案：您此次上传的模型名称为 测试，格式为 RVT，大小为 23.39 MB
  • 子文案：模型检测通过
  • 按钮：完成

状态3 — 检测不通过：

  • 文案：您此次上传的模型名称为 测试，格式为 DEM，大小为 23.39 MB
  • 失败原因（按实际情况显示其一）：Revit2021 以上高版本，请导出 IFC 格式后重新上传 / 格式不符：OSGB 压缩包内文件格式不对，请检查后重新上传
  • 子文案：模型检测不通过
  • 按钮：完成

交互流程：

1. 上传后自动触发检测，状态变为"检测中"

3.9 轻量化

对应原型文件： 轻量化.html

功能描述： 对 GLB 格式模型执行轻量化，采用二次误差边坍缩算法减面 + Draco 压缩 + 纹理压缩。页面分 4 个流程状态展示。

3.9.1 模型处理方案选择

提供4种处理方案，除「自定义处理」外，其余3种方案的参数均为预定义值、不可修改（参数输入框/开关置灰禁用）。各方案说明如下：

1. 推荐处理（Recommend）【默认选中】

  • 适用场景：大多数数字孪生项目，平衡模型精度与文件体积
  • 预设参数（不可修改）：
  • 模型减面：简化率 0.60，错误率 0.0001，勾选「保持边界」「保持外观」
  • 模型压缩：纹理格式 WEBP，纹理质量 75；勾选 draco压缩、去重复、索引重排
  • 模型合并：全部辅助选项不启用

2. 极限处理（Utmost）

  • 适用场景：大屏海量模型、移动端低配环境，追求最小模型体积，适度牺牲细节
  • 预设参数（不可修改）：
  • 模型减面：简化率 0.20，错误率 0.1000；勾选「保持边界」，取消「保持外观」
  • 模型压缩：纹理格式 WEBP，纹理质量 60；勾选 draco压缩、去重复、索引重排
  • 模型合并：勾选「展平层级」「GPU实例化」，取消「材质合并」

3. 无损处理（Lossless）

  • 适用场景：对模型外形精度要求极高，不做几何体简化，仅做数据压缩优化
  • 预设参数（不可修改）：
  • 模型减面：简化率 0.60，错误率 0.0001，勾选「保持边界」「保持外观」（几何不执行删减）
  • 模型压缩：纹理格式 WEBP，纹理质量 100；勾选去重复、索引重排，取消 draco压缩
  • 模型合并：全部辅助选项不启用

4. 自定义处理（Customize）

  • 适用场景：用户自定义参数，灵活调整各模块配置
  • 交互特点：所有参数输入框/开关均可编辑（参数为可用状态），用户可手动开启/关闭「模型减面」「模型压缩」「模型合并」三大处理模块，自由调整全部参数

交互规则注释：

>

* 推荐处理、极限处理、无损处理：参数为预定义值，参数输入框/开关为禁用状态（灰色不可编辑），用户无法修改参数数值。

* 自定义处理：参数输入框/开关为可用状态，用户可自由编辑参数。

* 切换方案时：选中「推荐/极限/无损」→ 参数自动填充为预设值并锁定禁用；选中「自定义」→ 参数解锁为可编辑状态。

* 用户手动修改任意参数后，自动切换选中「自定义处理」标签。

3.9.2 模型预览区域（画布）

1. 实时载入待处理三维模型，支持常规三维操作：旋转、平移、缩放查看模型效果；

2. 点击【轻量化模型】按钮后，即轻量化任务执行期间，画布遮罩展示加载动画 + 文字「正在轻量化中……」；

3. 任务完成后，右下角弹出模型处理报告悬浮面板，展示轻量化前后对比指标：

  • 模型文件大小、三角面数量、网格数量、纹理大小；
  • 附加信息：节点数量、材质数量、图元数量、动画数量；
  • 底部展示状态文字：压缩减面成功。

  • 若取消勾选【模型减面】，后台不执行几何体简化逻辑，仅执行压缩/合并；
  • 若取消勾选【模型压缩】，不对纹理、几何进行编码压缩；

4. 任务机制：轻量化采用异步任务，支持用户跳转页面，在【任务管理】统一查看全部处理队列；

5. 方案切换规则：选「推荐/极限/无损」→ 参数锁定禁用；选「自定义」→ 参数解锁可编辑；手动改参数 → 自动切至「自定义」。

交互流程：

1. 仅 GLB 支持轻量化（手工模型和 BIM 数据后台自动转 GLB 后可操作），入口仅对可轻量化模型显示

2. 选择处理方案（推荐/极限/无损参数禁用，自定义可编辑），设置参数后点击「轻量化模型」→ 弹窗提示任务已创建 → 进入 Loading 状态

3. 任务完成后，右下角弹出处理报告，展示前后对比数据；可保存/下载/还原模型

4. 已轻量化可再次轻量化，但不保证成功，可能失败原因是模型本身已经足够轻量了，再进行轻量化算法会报错
